# 05 メニュー・ポーズ・設定を足すときの定石

- **スタート後のメニュー**: 新しいモード番号を足し、表示と入力の処理を持たせる（その間ゲーム本体の処理は呼ばれないので止まる）。始めるときにスプライトの先頭バイトを消し、ゲームの画面リセットのルーチンを `jsr` で使い回して画面を消す。
- **ポーズ**: ゲームのモードの入口をラッパーに差し替え、プレイ中に 1P START の押し始め（エッジ）を見て別のモードへ移る。メニューを出す範囲のタイルを RAM に退避 → 描く → 閉じるときに戻す。
- **ゲームオーバーを選ぶ**: 残機0・プレイヤーのフラグ0・ゲームオーバーの状態へ直接移る。
- **設定の初期化**: 決定したときにメニューの「初期化済みの印」を消すと、次のゲーム（ゲームオーバーの後）は標準の値から始まる。電源を入れた直後の RAM は不定なので、印（例 0xA5）で初期化済みかを判定する。
- **項目どうしの依存**（例: 前の枠が「なし」なら後ろも「なし」）は、毎フレームの正規化の処理で保証する。
- **入力の扱い**: 長押しで連続して動くか、押し始めだけかを決めて統一する。左右・ショットで値を変え、上下で項目を移る形が分かりやすい。
- **改造機能は改造メニューから始めたときだけ有効**にし、普通にコインを入れて始めたときは純正どおりにする（通常プレイへの副作用を避ける）。
- 表示の文字・属性・カーソルの注意は 02-patching.md の最後。
