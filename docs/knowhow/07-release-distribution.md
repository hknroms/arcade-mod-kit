# 07 リリースと配布

## パッチ

- 配るのは **BPS パッチだけ**（`tools/bps.py`）。ROM の中身は配らない。
- 公開するパッチは **最新と1つ前の版だけ**にして、古い版のパッチは消す（更新履歴の文章は全部残す）。
- `docs/versions.json` に版ごとの「変更点・確かめたこと・既知の問題・パッチ（元と後の CRC）」を記録する。説明文の元は `docs/dev/notes/<版>.json`。前の版の「既知の問題」は次の版にも引き継ぐ。

## 配布ページ

- GitHub Pages（main の /docs）に置く。gradius3 の `docs/index.html` は、**純正 ROM をドロップするとブラウザの中だけで BPS を当て、MAME の roms フォルダにそのまま入れられる zip を作る**形（ROM はどこにも送られない）。新しいタイトルはこれを写して直す。
- テストプレイの報告は、配布ページのボタンから Issue のテンプレート（版が入力済み）へ。
- 共同作業のまとめページ（docs/status.html）は、配布ページからはリンクせず、協力者に URL を直接渡す。

## 版の管理

- ビルドに版を書き込み（03）、リリースのスクリプトで一致を確かめる。
- 2人以上がリリースできる場合: 始める前に main を最新にし、versions.json の次の番号を付ける。push が拒否されたら上書きせず、取り込んで番号を付け直してからやり直す。
- **配布ページへの公開の前には、管理者に確認する**（それ以外の push は確認不要）。

## 環境ごとの注意

- **MAME4droid（0.289）**: UI の一覧から改造 ROM を起動できない（SHA-1 が純正と違い「チェックサムが正しくない」で止まる。ファイルの加工では回避できない）。回避案: フロントエンド（Daijishou / ES-DE など）から直接起動、または「アプリで開く」（未検証）。
- **実機（基板）**: MAME のような照合は無い。ゲーム自身の起動時 ROM チェックは、メイン・サブ・サウンドとも合計を補正しておく。
- PS5 コントローラーを Windows の MAME で: Tab → Input (this Machine)、ダメなら DS4Windows / Steam 入力。
