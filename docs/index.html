新しいタイトルを始める

人がやること（GitHub の画面で・数分）
  1. このひな形から新しいリポジトリを作る（公開で。名前はタイトルが分かるもの）
  2. Claude のアプリの Configure で、新しいリポジトリを Select repositories に足して Save
  3. ピカドラムからも作業するなら、新しいリポジトリの Settings → Collaborators で招待し、ピカドラム側で承認
  4. 配布ページを出すときは Settings → Pages で「main」「/docs」を選んで Save
Claude に頼むこと
新しい会話で新しいリポジトリをつなぎ、純正ROMの zip を添付して、次の一文を送る（○○ などは書き換える）
hknroms/○○ の SETUP.md の「Claude がやること」を進めて。タイトルは△△、MAME のセット名は□□。
Claude は title.json を埋め、手順書の空欄を埋め、MAME のビルド済みを用意し、解析を始めます。詳しくは SETUP.md。

ノウハウ集

01 解析の進め方ROM の並べ方・状態機械・RAM の特定・書き込み元の追跡
02 パッチの入れ方空き領域・アセンブラ・フック・テーブル拡張・レジスタ
03 ROM チェックと版表示起動時の ROM チェックを通す・起動画面に版と日時を書く
04 MAME での検証ビルド済み MAME・画面なしで回す・分かること分からないこと
05 メニュー・ポーズメニュー・ポーズ・設定を足すときの定石
06 再現できるビルドROM 由来データの扱い・公開版と同じものを作れるか確かめる
07 リリースと配布BPS・配布ページ・版の管理・環境ごとの注意
08 共同作業Issue のコマンド・まとめページ・要望

ひな形に入っているもの

CLAUDE.mdClaude への共通の決まり（ROM の扱い・push のルール・記録の置き場所）
VERIFY.md COLLAB.md協力者の Claude 向け手順書（検証／調査・実装・素材・資料）
docs/status.html共同作業のまとめページ（全体・要望・種類別・協力者・始め方）
docs/dev/STATUS.md（現在地）・TECH.md（技術メモ）・notes/（リリースの説明文）
.github/共同作業ボットと Issue のテンプレート（検証・作業・要望・テストプレイ報告）
tools/68000 アセンブラ・逆アセンブラ、BPS、ROM の組み立てと合計の補正、MAME のビルドと配置、空欄を埋める道具
